# DienerHaus Website

Website der DienerHaus GmbH – Bauträger in Jockgrim.

Statische Website (HTML/CSS/JS, keine Build-Tools nötig). Einfach `index.html` im Browser öffnen oder den Ordner auf einen Webserver hochladen.

## Struktur

- `index.html` – Startseite
- `impressum.html`, `datenschutz.html` – rechtliche Seiten
- `css/style.css` – Styles
- `js/script.js` – Rechner, Navigation, Cookie-Banner
- `assets/` – Bilder, Logos, Downloads (Exposés)
